# PinkRooster.Extensions.AI.Antigravity

An `IChatClient` ([Microsoft.Extensions.AI](https://learn.microsoft.com/dotnet/ai/microsoft-extensions-ai)) implementation on top of the Antigravity CLI (`agy`) print mode.

Status: under construction, version 0.1.0 not released. The requirements are in `docs/specification.md` and the design in `docs/software-design.md`; this README is written in full before the first release.
