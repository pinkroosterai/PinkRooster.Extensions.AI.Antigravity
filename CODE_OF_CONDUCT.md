# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good faith, keep feedback about the work and not the person, and no harassment of any kind.

To report a problem, open a [private security advisory](https://github.com/pinkroosterai/AgyChatClient/security/advisories/new) and say it is a conduct report; only the maintainers see it. They will keep the report confidential and decide on a response, up to removing comments or banning a participant.
